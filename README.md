# HEX 1000

Local-first tools for working with AI assistants. Everything runs on your own PC, with a local Ollama model where a model is needed.

- [Prompt Coach](https://github.com/HEX-1000/prompt-coach): checks a prompt before you send it to Claude, asks about anything unclear and recommends a model and effort level.
- [Token Optimization System](https://github.com/HEX-1000/token-optimization-system): a local MCP server that gives Claude a few relevant sections of your files instead of whole documents.
- [Research Radar](https://github.com/HEX-1000/research-radar): a daily scan of new repositories, papers and models that fit your interests.
